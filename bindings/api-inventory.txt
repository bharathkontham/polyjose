# polyjose binding API inventory: the 0.1.0 public API of every binding.
#
# The machine-readable copy of ADR 0030 §4, in its order: every operation, every record with its
# fields, and every error code that the bindings expose (Rust surface, JS facade, Node, WASM,
# Kotlin and Swift). Names are the host form (ADR 0030 §2): operations and fields camelCase,
# records UpperCamel. The Rust surface uses the same names in snake_case.
#
# STABILITY (ADR 0030 §8): these names are the 0.1.0 public API of four platforms. Changing,
# renaming or removing an entry is a breaking change and is human-gated at Gate 2 ("the public
# API of a binding", pipeline.md). Adding an operation or an optional field is not breaking, but
# it is still a public API change: add it here in the same change.
#
# scripts/check-binding-api.sh checks each binding's exported names against this file (one mode
# per binding, scripts/check-binding-api.d/), and the code list against the core's
# polyjose::Error::CODES (crates/polyjose/src/error.rs), in the same order.
#
# Format: one entry per line; blank lines and lines starting with '#' are ignored, and leading
# whitespace is only layout.
#   op <name>              an operation
#   record <Name>          a record (options or a result); the field lines below belong to it
#   field <name>           a required field
#   field <name>?          an optional field: absent means the core default (Rust Option)
#   field <name> = false   a flag: absent means false (Rust bool)
#   code <Code>            an error code (ADR 0030 §5)
